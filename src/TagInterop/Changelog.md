# Change Log

The change log describes what is "Added", "Removed", "Changed" or "Fixed" between each release.

## 2.0.0

### Changed

* Require PHP 8.2 or later.
* Require `psr/cache` 3.
* Add native parameter and return types to the tag interfaces.
* Declare taggable item return types on taggable pool reads.
