# Changelog

The change log describes what is "Added", "Removed", "Changed" or "Fixed" between each release.

## 1.0.4

### Changed

* Test against Array Adapter 2 and 3.

## 1.0.3

### Fixed

* Allow installing with `psr/simple-cache` 2 or 3.

## 1.0.0

### Changed

* Require PHP 8.2 or later.
* Require `psr/simple-cache` 3.
* Add native parameter and return types to the `remember()` helper.

## 0.2.0

### Changed

- Require PHP 7.4 or later and support PSR Cache 2.

### Fixed

- Update the test configuration for current PHP and PHPUnit versions.

## 0.1.0

### Added

- New utility repo
- `remember` function
